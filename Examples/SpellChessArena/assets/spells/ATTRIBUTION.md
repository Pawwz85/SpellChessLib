# Asset attribution

This file documents the third-party artwork used by SpellChessArena, including
the spell icons stored alongside this file and the chess piece set used by the
project.

The spell icons in `default/` are adapted from [Game-icons.net](https://game-icons.net/).
The original icons are licensed under [Creative Commons Attribution 3.0 (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

## Modifications

The original monochrome PNGs were rasterized to 165 × 165 transparent RGBA PNGs for the SpellChessArena sprite loader. The black source background was removed, the active icons were recolored for the spell UI, and inactive variants were made using a neutral gray tint with reduced opacity. The source icon artwork and silhouettes were not otherwise changed.
